# Getting Started with Create React App

## Integração com a API Laravel

Este frontend consome a API pública do projeto Laravel Onde Passa o Jogo.

1. Copie `.env.example` para `.env.local`.
2. Defina `REACT_APP_API_BASE_URL` com a URL base do Laravel, sem `/api` no final:

```env
REACT_APP_API_BASE_URL=https://maicon.receiv.it
```

3. Inicie o frontend com `npm start`.

O React consulta `GET /api/v1/fixtures` e envia os filtros `from`, `to`, `team` e `competition`. A API retorna somente partidas aprovadas e publicadas. Nenhuma chave de provedor esportivo ou de IA deve ser colocada neste projeto, porque variáveis expostas no navegador não são secretas.

Durante o desenvolvimento local, o Laravel precisa permitir a origem `http://localhost:3000` em `CORS_ALLOWED_ORIGINS`. Para mais de uma origem, separe os valores por vírgula.

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).
